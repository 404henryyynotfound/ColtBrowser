# ColtBrowser

A browser **built for Muir Middle School (HVS)** by **Henry Green**, which is a part of the ColtApps business.

---

## Our Apps

### 1. ColtBrowser Suite (Included in This Repository)
A sleek, privacy-focused web browser simulator powered by DuckDuckGo, available in three editions tailored to every student and device:

#### Quick Access — ColtBrowser
* **For HVS Students (No Download Required):**
  * **ColtBrowser (Standard / v1.1.0 BETA):** [sites.google.com/hvs.org/coltbrowser](https://sites.google.com/hvs.org/coltbrowser)
  * **ColtBrowser LITE:** [sites.google.com/HVS.org/coltbrowser-lite](https://sites.google.com/HVS.org/coltbrowser-lite)
  *(Must be signed into your HVS Google account to access the Google Sites portals.)*
* **Download & Run Locally (Downloads Folder):**
  1. Click the **Code** button on this repository and select **Download ZIP** (or download `coltbrowser.html`, `coltbrowser-lite.html`, or `coltbrowser-dev.html` directly).
  2. Open your computer's **Downloads** folder and extract the ZIP file if needed.
  3. Double-click any of the `.html` files to launch that edition directly in any modern web browser—no installation required.

#### ColtBrowser Editions
* **ColtBrowser DEV (`v2.0.0-nightly`):** Built for student developers and coding classes (`coltbrowser-dev.html`). Features dockable DevTools (`F12`), an interactive JS Console REPL, a live HTML/CSS/JS Sandbox (`colt://sandbox`), Experimental Flags (`colt://flags`), and DuckDuckGo developer bangs (`!gh`, `!mdn`, `!wiki`).
* **ColtBrowser LITE (`v1.0 LITE`):** Engineered for **Muir Middle School Chromebooks** and low-RAM hardware (`coltbrowser-lite.html`). Uses native system fonts, an 8-tab memory cap, high-contrast Muir Colts Navy & Gold styling, and a lightweight Quick Note box.
* **ColtBrowser `v1.1.0 BETA`:** The full-featured standard edition (`coltbrowser.html`) with 5 custom themes, 6 accent colors, `colt://settings`, a 25-minute Study Timer, customizable shortcuts, and a Split-View Scratchpad.

### 2. ColtEmulate (Separate Repository)
**Repository:** [github.com/404henryyynotfound/colt-emulate](https://github.com/404henryyynotfound/colt-emulate)

A cross-platform emulation environment built to run `.dmg`, `.exe`, and other executable or disk image files from different operating systems directly in a separate OS environment. Check out the dedicated **ColtEmulate** repository for source files, setup instructions, and supported file formats.
